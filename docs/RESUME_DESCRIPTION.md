# Résumé description

## SchemaSynchronizer — Creator and Maintainer

Designed and open-sourced **SchemaSynchronizer**, an Apache-2.0 Java library and
standalone CLI that keeps relational database schemas aligned with a version-controlled
desired-state definition. It automatically applies safe, non-destructive changes,
surfaces destructive or ambiguous changes as executable SQL for human approval, and
supports ordered, checksummed change sets for constraints, backfills, and other
intentional operations. Built Spring Boot integration and tested dialect support for
PostgreSQL, MariaDB, and MySQL, with compatibility verification for Percona Server and
TiDB. Published the library through Maven Central with signed artifacts, source and
Javadoc packages, and production-oriented documentation.

**Technologies:** Java 21, JDBC, Spring Boot, PostgreSQL, MariaDB, MySQL, Maven,
Docker, JUnit, AssertJ, PGP, Maven Central.
